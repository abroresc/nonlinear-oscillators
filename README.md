# Numerical Integration of Non-Linear Oscillators via RK4

## Background

This repository studies a damped harmonic oscillator using a fourth-order Runge-Kutta integrator implemented from scratch in Python. The governing equation is

$$
\frac{d^2x}{dt^2} + \gamma \frac{dx}{dt} + \omega_0^2 x = 0,
$$

where:

- $x(t)$ is the displacement,
- $\gamma$ is the damping coefficient,
- $\omega_0$ is the natural angular frequency.

To integrate the dynamics numerically, the second-order ordinary differential equation is rewritten as a first-order system:

$$
\frac{dx}{dt} = v,
$$

$$
\frac{dv}{dt} = -\gamma v - \omega_0^2 x.
$$

This formulation makes the problem suitable for standard explicit time-stepping schemes such as RK4.

## Algorithm

Let the state vector be

$$
\mathbf{y}(t) =
\begin{bmatrix}
x(t) \\
v(t)
\end{bmatrix},
$$

with evolution equation

$$
\frac{d\mathbf{y}}{dt} = \mathbf{f}(t, \mathbf{y}).
$$

For a time-step $\Delta t$, the classical fourth-order Runge-Kutta update is:

$$
k_1 = \mathbf{f}(t_n, \mathbf{y}_n),
$$

$$
k_2 = \mathbf{f}\left(t_n + \frac{\Delta t}{2}, \mathbf{y}_n + \frac{\Delta t}{2}k_1\right),
$$

$$
k_3 = \mathbf{f}\left(t_n + \frac{\Delta t}{2}, \mathbf{y}_n + \frac{\Delta t}{2}k_2\right),
$$

$$
k_4 = \mathbf{f}\left(t_n + \Delta t, \mathbf{y}_n + \Delta t\,k_3\right).
$$

The next state is then computed from

$$
\mathbf{y}_{n+1} = \mathbf{y}_n + \frac{\Delta t}{6}\left(k_1 + 2k_2 + 2k_3 + k_4\right).
$$

In this repository, the RK4 solver is implemented directly with `numpy`, without using `scipy.integrate`.

## Validation

The numerical solution is compared against the underdamped analytical solution

$$
x(t) = A e^{-\gamma t/2}\cos(\omega t + \phi),
$$

where

$$
\omega = \sqrt{\omega_0^2 - \frac{\gamma^2}{4}}.
$$

Residuals are computed as the pointwise difference between the RK4 trajectory and the analytical reference. For the verified configuration in this repository, a maximum residual of approximately $0.12$ is treated as an expected consequence of numerical dispersion for the chosen time-step. That mismatch confirms the simulation is genuinely numerical rather than analytically reproduced, while still remaining close enough to validate the RK4 integrator's accuracy and convergence behavior.

## Files

- `oscillator.py`: RK4 solver, analytical comparison, residual calculation, and plotting.
- `requirements.txt`: Python dependencies.
- `oscillator.png`: Verified output plot generated by the simulation.

## Usage

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the simulation:

```bash
python3 oscillator.py
```

Display the plot interactively:

```bash
python3 oscillator.py --show
```
